# lotto539-math

今彩539 的組合數學：連碰、立柱、拖膽的組數，單組命中機率，包牌「至少中一組」的機率，以及期望值。
零依賴的 ES module，瀏覽器與 Node 都能用。

線上試算：<https://sentinelbotsaas-hub.github.io/lotto539-math/>

## 為什麼做這個

坊間的「包牌公式」「穩中技巧」幾乎都只講組數和中了能拿多少，不講機率與期望值。
這個套件只做一件事：把數字算對、把公式攤開，讓人自己判斷。

結論先講：**包牌只放大成本，不改變期望值。** 每組的期望值只跟星數與賠率有關，跟你包幾碼無關。

## 公式

539 從 1–39 開出 5 個號碼，總共 C(39, 5) = 575,757 種結果。

| 項目 | 公式 |
|---|---|
| 連碰（全車）組數 | C(n, k) |
| 立柱／拖膽組數 | C(拖碼數, k − 膽碼數) |
| 單組 k 星全中機率 | C(39 − k, 5 − k) / C(39, 5) |
| 每投 1 元期望報酬 | 賠率 × 單組機率 − 1 |
| 連碰至少中一組 | Σ_{j=k..5} C(n, j)·C(39 − n, 5 − j) / C(39, 5)（超幾何分布） |

## 算出來的數字

以民間常見賠率（二星 53、三星 580、四星 7,500 倍；各地不同，以實際為準）：

| 星數 | 單組機率 | 每投 100 元平均拿回 |
|---|---|---|
| 二星 | 1 / 74.1 | 71.5 元 |
| 三星 | 1 / 913.9 | 63.5 元 |
| 四星 | 1 / 16,450.2 | 45.6 元 |

二星連碰，選越多碼：

| 選幾碼 | 組數 | 至少中一組的機率 |
|---|---|---|
| 5 | 10 | 11.40% |
| 8 | 28 | 26.77% |
| 10 | 45 | 38.12% |
| 15 | 105 | 64.93% |

命中率上升，是因為買的組數變多；每一組的期望值都還是 71.5 元／100 元。

## 用法

```js
import { comboCount, pHit, evPerUnit, pAtLeastOneCombo, pillarCount } from "./lotto539.mjs";

comboCount(8, 2);          // 28 組
pillarCount(1, 10, 2);     // 1 膽 10 拖的二星 = 10 組
1 / pHit(3);               // 913.9
evPerUnit(53, 2);          // -0.285
pAtLeastOneCombo(10, 2);   // 0.3812
```

自我檢查：`node test.mjs`
